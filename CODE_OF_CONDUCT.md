# Code of Conduct

This project adopts the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.
The official text (Our Pledge / Our Standards / Enforcement Responsibilities / Scope /
Enforcement) prevails.

## Summary (informal, for quick reference)

- **Expected**: respect for different experience levels and viewpoints; accept
  constructive criticism; keep it about the work; show empathy to other community
  members.
- **Unacceptable**: personal attacks, discriminatory language, sexualised language or
  imagery, public or private harassment, publishing others' private information without
  permission, and other conduct that would be inappropriate in a professional setting.
- **Scope**: this repository (issues / PRs / discussions) and any public or private
  communication conducted in the context of this project.

## Enforcement

- Reports: **dingiv456@163.com** (private; do not open a public issue);
- The maintainer will review and respond, and take **necessary and proportionate**
  action (reminder → warning → temporary ban → permanent ban);
- The maintainer is obligated to keep reporters' identities confidential.
